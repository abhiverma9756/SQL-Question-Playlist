## 🔥 Example

### Problem

**Find the second largest element in an array.**

### Concept

* Arrays
* Traversal
* Conditional Logic
* Time Complexity

### Approach

Instead of sorting the complete array, maintain two variables:

```python
largest = float('-inf')
second_largest = float('-inf')

for num in arr:
    if num > largest:
        second_largest = largest
        largest = num
    elif num > second_largest and num != largest:
        second_largest = num
```

### Complexity

```text
Time Complexity  : O(n)
Space Complexity : O(1)
```

### Key Learning

> A problem that can be solved using a single traversal should not always require sorting.
